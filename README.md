# Bernard Shambrook's Notebook, 1941

A reading transcription of the pocket notebook kept by Sgt B. E. Shambrook, NX40242, 2nd AIF, from embarkation on the *Queen Elizabeth* in Sydney on 9 April 1941 through his first months in Palestine.

The site is a single page: `index.html`. It shows each page of the notebook beside its transcription, with a map of every place and date the notebook mentions.

- `pages/` holds the enhanced page images (contrast-flattened, cropped, spreads split into left and right pages), numbered in notebook order.
- `thumbs/` holds the small versions used in the page layout.

Readings marked [?] are best guesses at difficult handwriting and are open to correction. Edit the text in `index.html` directly.

Hosted with GitHub Pages from the `main` branch.
